# s21_decimal

## Описание

`s21_decimal` — статическая библиотека на C11, реализующая собственный
десятичный тип данных для точных вычислений с целыми и дробными числами. Тип
построен на десятичном представлении, удобном для финансовых расчетов:
96-битная мантисса, бит знака и степень масштабирования от 0 до 28 знаков после
запятой. Такой подход позволяет избежать характерных для `float` и `double`
ошибок бинарного округления.

Библиотека поддерживает:

- арифметические операции: сложение, вычитание, умножение и деление;
- операции сравнения decimal-значений с разными знаками и степенями;
- преобразования между `int`, `float` и `s21_decimal`;
- дополнительные операции округления: `floor`, `round`, `truncate`, `negate`;
- внутренний big-decimal тип для промежуточных вычислений и обработки
  переполнений;
- unit-тесты на базе Check и генерацию отчета покрытия.

Публичный интерфейс описан в `src/s21_decimal.h`, а реализация разделена по
файлам в директории `src`:

- `s21_arithmetic.c` — арифметика;
- `s21_compare.c` — сравнение значений;
- `s21_convert.c` — преобразование типов;
- `s21_another.c` — округление и работа со знаком;
- `s21_big_decimal.c`, `s21_base.c`, `s21_extra.c` — внутренняя логика decimal;
- `s21_test_*.c` — unit-тесты.

## Сборка

```bash
cd src
make
```

Команда собирает статическую библиотеку:

```text
src/s21_decimal.a
```

## Тесты

```bash
cd src
make test
```

Цель `test` собирает и запускает набор тестов на базе Check.

## Отчет покрытия

```bash
cd src
make gcov_report
```

Цель запускает тесты с флагами покрытия и формирует HTML-отчет в
`src/report/index.html`.
